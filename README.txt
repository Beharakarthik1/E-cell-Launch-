AITAM E-CELL — editable plain HTML/CSS/JavaScript project

Files:
- index.html: complete page structure/content
- style.css: all styling; no Tailwind dependency
- script.js: mobile menu, About card flips, and interactive Domains carousel
- aitam-ecell-logo.jpg and favicon.ico: recovered public assets

Added domain:
- Curriculum Integration — connects classroom learning with entrepreneurship, innovation, and practical problem-solving.

Run locally:
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Right-click index.html and choose Open with Live Server.

Note: This is an editable plain HTML/CSS/JS reconstruction based on the public deployed bundle and HAR assets. The recovered site was originally built as a compiled React/Tailwind bundle; this version removes Tailwind and reconstructs the presentation and interactions. Because the original authoring source was not present in the HAR, exact pixel-level identity cannot be guaranteed. The added Curriculum Integration domain is new content requested by the user.
